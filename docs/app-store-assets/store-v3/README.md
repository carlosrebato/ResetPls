# ResetPls — App Store V3

Seis composiciones, ES/EN, PNG RGB 1320×2868 sin alfa. Orden: 01 principal, 02 bloqueo, 03 widgets.

Marco oficial Apple iPhone 16 Pro Max, titanio natural. PNG original 1470×3000; se reduce a 1000 px de ancho, no se amplía. Fuente: https://developer.apple.com/design/resources/ (Bezel-iPhone-16.dmg).

01: Claude ámbar, Codex verde. Historial de muestra con mesetas y reset.
02: widgets nativos, rectangular a la izquierda y círculos de Claude/Codex a la derecha, siguiendo la distribución de referencia. Fondo neutro y contexto de bloqueo compuesto. No incluye ninguna foto personal; no es una captura directa de SpringBoard.
03: fondo claro, mayoría de estados verdes con aviso ámbar y un mensaje rojo puntual.

Copies aprobados; sin marca superior adicional. No se ha subido a App Store Connect.
