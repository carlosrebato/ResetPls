# ResetPls 0.1.7 (48)

Signed Mac releases and automatic updates now live in the public ResetPls
repository. This is a one-time manual migration from the retired AI Usage repo.

## Install / Instalar

Quit ResetPls (or AI Usage), unzip **ResetPls-0.1.7.zip**, and drag **ResetPls.app**
into Applications, replacing the previous app. If you still have AI Usage.app,
remove that old app bundle after quitting it. Do not run both apps.

Cierra ResetPls (o AI Usage), descomprime **ResetPls-0.1.7.zip** y arrastra
**ResetPls.app** a Aplicaciones, reemplazando la anterior. Si todavía tienes
AI Usage.app, retira esa app antigua después de cerrarla. No abras ambas.

Your saved connections, preferences and stable/beta channel selection remain
unchanged. Subsequent updates are automatic from ResetPls; this ZIP works for
both stable and beta users.

Se conservan tus conexiones, ajustes y elección de canal estable/beta. A partir
de esta instalación, las actualizaciones automáticas llegan desde ResetPls.
El mismo ZIP sirve para ambos canales.

## Included

- Consistent session and weekly pace assessments, copy and tooltips on Mac/iOS.
- Secondary weekly-risk information for providers with session limits.
- Token charts return to zero on inactive days rather than cutting the line.
- Shared Help, Privacy and issue-report links to the current public project.
- New public Sparkle feed, retaining the existing signing key and app identity.

Universal Mac build (Apple Silicon and Intel), macOS 15 or later. Developer ID
signed and Apple notarized. iOS source is included in the repository; this ZIP
contains the Mac app, not an iOS installer.
